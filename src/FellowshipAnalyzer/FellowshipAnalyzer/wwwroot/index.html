Fellowship Analyzer

Improve your play with hero-specific feedback and statistics. Fellowship Analyzer reads the combat logs you upload to Fellowship Logs and turns raw events into actionable suggestions for the hero you played.

Paste a report code, report URL, or character profile URL to analyse a dungeon run.

  • Heroes: which heroes are analysed, and how complete each one is.
  • News: what changed in the analysis recently.
  • About: what the analysis does and how to contribute.
  • Privacy: no cookies, no ads, no tracking.
